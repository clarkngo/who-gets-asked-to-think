Why this matters

Beginners increasingly learn to program alongside AI assistants. An answer that only hands over working code can get the task done without teaching anything. An answer that explains how the code works, says where it might break, and suggests how to check it gives the learner something to think with. Earlier research found that generative AI can widen the gap between novices who are already doing well and those who are struggling (Prather et al., 2024). It also found that learners who aren't native English speakers face extra barriers in programming (Guo, 2018).

This pilot asks a narrow version of that question: when a beginner asks for help, does the AI ask them to think? And does the answer change with how they ask, and the language they ask in?

Research questions

  1. Evaluative judgment. How often do responses help the learner judge the code (by explaining how it works, stating assumptions and limits, flagging uncertainty, suggesting how to test it, or inviting the learner to predict or modify it), rather than just handing it over?
  2. Framing. Does this differ between "just make it" and "help me learn" requests?
  3. Language. Does it differ between English and Taglish, the everyday Tagalog–English mix many Filipino learners type in?
  4. Correctness. Does the generated code actually work when run against hidden tests?

Design

This is an audit of AI models, not a study of people: no learners take part. The same beginner requests go to several models, and every response is saved, run, and coded. See the step-by-step process diagram →

20original beginner Python tasks
2framings: "just make it" / "help me learn"
2languages: English / Taglish
3models

Tasks
Twenty short tasks written for this project, not taken from textbooks or courses. They cover conditionals, loops, strings, lists and dictionaries, at three levels of difficulty. Examples include splitting a restaurant bill, finding the longest practice streak, and planning pages to read per day.
Prompts
The task text is identical across the two framings; only the opening and closing sentences change. The Taglish prompts were written by the author, a native speaker, rather than machine-translated, and each was checked line by line against the English for meaning. Function names and examples stay in English in both languages, as they would in a real classroom.
Models
Claude Sonnet 5.5 (Anthropic), a Gemini model (Google), and qwen2.5:7b, a free model run locally. Every call logs the exact model ID, its settings, and a timestamp.
Correctness
The code in each response is run in an isolated sandbox (no network, time limits) against hidden unit tests. The tests only check what the prompt actually asks for. Edge cases the prompt leaves open are recorded but not scored.
Coding the explanations
A stratified sample of about 200 responses is hand-coded by the author with a written codebook. If an AI model helps pre-code the rest, its agreement with the human codes (Cohen's κ) is reported. The human codes count as ground truth.

An example prompt

Task T01, as a learner might type it. Each language has a "just make it" version and a "help me learn" version.

English

i need a python function called split_bill(total, people, tip_percent). it should add the tip to the total and then split it evenly, so it returns how much each person pays, rounded to 2 decimal places. for example split_bill(100, 4, 20) should give 30.0

Taglish

kailangan ko ng python function na pangalang split_bill(total, people, tip_percent). dapat netong i-dagdag ang tip sa total at tapos i-split evenly para mag-return kung magkano babayaran ng tig-isang tao, rounded to 2 decimal places. halimbawa, split_bill(100, 4, 20) dapat magresult sa 30.0

The two framings

"Just make it": English / Taglish

[task]

can you just write it for me? i just need it to work.

pwede bang ikaw na lang mag-sulat para sa akin? kailangan ko lang itong gumana.

"Help me learn": English / Taglish

i'm learning python and i want to actually understand this, not just copy it.

nag-aaral ako ng python and gusto ko talaga itong matutunan at ayokong kopyahin lang.

[task]

can you help me learn how to do it?

pwede mo ba akong turuan paano gawin?

The "just make it" version deliberately doesn't say "no explanation". The point is to see what the AI offers on its own when a learner just wants working code.

What we look for in each response

Explains how it works
Says why the code works, not just what it does.
States assumptions or limits
For example: "this assumes there's at least one person; with 0 you'll get an error."
Flags uncertainty
Admits the answer might be wrong or hasn't been checked.
Suggests how to verify
Gives concrete inputs or tests the learner can try.
Invites the learner to think
Asks them to predict, explain, or change something specific.
Scaffolds instead of solving
Gives hints or a partial solution and leaves the rest to the learner.

Measured automatically as well: whether the answer comes back in the learner's language, how much is code versus explanation, and whether the code passes the tests.

Limitations

  • It's a pilot. 20 tasks, 2 languages and 3 models. The findings are descriptive and meant to test the method, not to settle the question.
  • Models change. Hosted models are updated without notice, so results reflect the model versions and dates logged for each call.
  • Models, not products. Prompts go straight to each model, without the extra instructions that apps like chatbots or code editors add, so results may differ from what learners see in those apps.
  • One coder. The explanations are hand-coded by one person. Any AI-assisted coding is checked against those human codes.
  • Claude's dual role. Claude, one of the audited models, also helped build the tools and compare the Taglish prompts against the English. The prompts themselves were written by the author.
  • No learners. This study says nothing about what students actually learn, only about what the AI responses contain.

Next steps

Many Filipino-Chinese (Chinoy) learners also write in Mandarin mixed with English, or text in Hokkien. Extending the audit to these languages needs native-speaker collaborators to write and check the prompts, so they are planned for after the pilot rather than included now.
